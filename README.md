## About

I'm an Informatics student specializing in **Software Engineering and Fullstack Development**, with a secondary focus on **Cybersecurity**. My work centers on building practical, well-structured web applications while deepening my understanding of data structures, algorithms, backend engineering, and system design.

Alongside development, I study security from both sides of the equation — how systems are attacked, and how they're detected, defended, and hardened — with particular interest in network security, security testing, and system hardening.

## Cybersecurity Focus

Cybersecurity is my secondary discipline, approached through the lens of both offense and defense:

| Area | Focus |
|---|---|
| Network Security | Traffic analysis, segmentation, hardening |
| Application Security | OWASP Top 10, secure coding practices |
| Vulnerability Assessment | Identifying and prioritizing weaknesses |
| Security Testing | Manual and tool-assisted testing |
| Offensive Security | Attack simulation fundamentals |
| Defensive Security | Detection, monitoring, response |
| Purple Team Operations | Bridging attack and defense workflows |
| System Hardening | Reducing attack surface on Linux systems |

**Guiding question:** How are systems attacked — and how are they detected, defended, and hardened in response?
